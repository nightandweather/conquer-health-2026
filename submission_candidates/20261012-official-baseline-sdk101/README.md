# 오늘 서버 실행을 확인할 공식 기본 후보 · SDK 1.0.1

2026-10-12 공식 [시작 패키지](https://nova.snubhai.org/docs/starter.zip)에서 받은
`run.py`, `nova_sdk.py`, `requirements.txt`의 원문 바이트를 그대로 보관합니다.
파일별 해시와 출처는 `source-manifest.json`에 있습니다. SDK 1.0.1은 공식 문서가
설명하는 Python 기본 User-Agent의 Cloudflare 거절 문제를 처리하며, 이 후보는
같은 시작 패키지의 `reasoning_effort='medium'` 기본 에이전트와 함께 사용합니다.
기존 프로젝트의 SDK 1.0.0, `run.py`, `dist/submission.zip`은 바꾸지 않습니다.

## 실제로 확인한 범위

`scripts/build_day0_submission.py`가 지정된 세 파일만 ZIP 루트에 넣습니다.
원문 SHA, 50 MB 압축 / 500 MB 해제 / 5,000개 파일 한도, 중복 경로·다른 경로·
심볼릭 링크·암호화·CRC와 해제된 원문 해시를 확인합니다. 같은 원문으로 만든 ZIP은
같은 바이트를 갖습니다. 기존 결과 폴더는 덮어쓰거나 재개하지 않습니다.

자격증명을 지운 별도 Python 프로세스에서 소켓 연결을 막고 ZIP만 임포트해
`prepare()`를 확인합니다. 합성 응답을 사용해 정상 SAY/EXAM/DONE과 최종 SOAP 제출,
종료 직전 기록 작성, 잘못된 EXAM의 턴 차감, 30자를 넘는 모델 출력 재요청,
환자 모델 일시 오류 재시도를 검사합니다. SDK 요청 헤더와 medium/2048 전달은
실제 HTTP 대신 메모리 응답으로 확인합니다. 이 오프라인 검사 중 실제 모델 호출·HTTP 전송은 0회입니다. 서버 샘플 실행의 모델 호출 수는 확인하지 못했습니다.

```bash
.venv/bin/python -m unittest tests.test_day0_submission -v
.venv/bin/python scripts/build_day0_submission.py
```

기본 출력은 Git에서 제외된
`results/codex-day0-submission-v1/build-20261012-sdk101-v1/day0-official-sdk101.zip`입니다.
다시 재현할 때는 `--output-dir`에 존재하지 않는 새 폴더를 지정합니다.
README나 매니페스트, HealthBench 결과, 공개 샘플 대본은 ZIP에 들어가지 않습니다.

## 오늘 참가자 화면에서 확인한 조건

제출 전 준비 시점에 로그인한 참가자 화면에서 기존 제출 0건,
오늘 샘플 검증 10회 남음을 확인했습니다. 리더보드 제출 선택지는
“지금은 접수 기간이 아님”으로 비활성화되어 있었습니다.
이는 공개 서비스 상태의 “이용 가능” 표시와 별개입니다.
오늘 공식 평가 1회가 실제로 남아 있거나 접수가 열렸다고 확정하지 않습니다.
그 준비 시점에는 새 ZIP의 업로드·샘플 검증·공식 평가 요청을 하지 않았습니다.

이후 사용자의 승인으로 같은 ZIP을16:45KST에 샘플 검증1회로 등록했습니다.
서버 파일 SHA는 로컬 ZIP과 일치합니다.16:57KST 후속 관측은 평가 중이며
첫 증례가 정상 종료(30턴·517초)로 표시됐습니다. 전체 완료·총점·서버 통과는
아직 미확인입니다.17:06KST에는 두 번째 증례도 정상 종료(30턴·536초)로
표시됐으며 전체 평가와 총점은 여전히 대기 중입니다. 공식 평가 요청은0회이며
같은 ZIP을 다시 요청하지 않습니다.
[현재 제출 기록](../../benchmarks/NOVA_DAY0_SUBMISSION.md)을 함께 확인하세요.

17:19KST 후속 확인에서 **검증 완료·평가 완료**, 공개 샘플3건 모두 정상 종료,
참고 총점 **42.179점**을 확인했습니다. 각30턴·517/536/567초입니다.
이후 점수는 이 공식 기본 코드의 샘플 기준선이며 새 검색·프롬프트의 개선 결과나
공식 리더보드 점수가 아닙니다. 서버 모델 호출 수는 미확인입니다.

공식 일정은 예선 10/12–10/22이며, 오늘은 예선 시작일입니다.
공식 평가는 팀·단계별 KST 하루 1회이고 샘플 검증은 이 횟수를 쓰지 않습니다.
리더보드 평가에서 코드가 실패하면 해당 일일 횟수를 사용합니다.
예선 마지막 날의 정확한 종료 시각은 확인한 공개 페이지에 없습니다.

새 검색·프롬프트·HealthBench 후보를 섞지 않았으며 성능 향상을 입증하지 않았습니다.
