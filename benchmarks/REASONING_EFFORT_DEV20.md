# 같은 지침에서 low·medium 추론 비교

2026-10-12에 개발용 20문항만 사용해 원래 grounded-v2 지침·원문 이력·temperature 0·출력 2,048토큰·문항당 1호출을 유지하고 `reasoning_effort`만 low에서 medium으로 바꿨습니다. 모델 digest와 20개 입력 해시의 동일성을 확인했습니다. 각 요청의 차이는 reasoning_effort뿐임을 확인했고, low 대조군은 원본 기록을 그대로 재사용했습니다. 원본 200문항 실행의 partial 상태와 바이트도 유지합니다.

실행기와 큐에 추론 설정을 전달하도록 구현했습니다. 기본 low 동작의 바이트 동일성과 요청·설정 변조 거부를 포함한 대상 테스트 46개, private 전체 회귀 188개, 화면 대상 17개가 통과했습니다. 표시 수정 후 전체 private 회귀 188개와 공개 패키지 검토·점수·범위·화면 대상 77개도 통과했습니다. 공개 저장소 전체 테스트를 실행한 것은 아닙니다. 독립 코드 감사도 완료했습니다. 화면 확인에서 요약 메모가 구체적 오류를 가리는 문제를 보완하여, 안전 오류 표시를 먼저 보여 줍니다. 판정·점수·범위·출처 결과의 바이트는 바뀌지 않았고 화면 메모만 갱신했습니다.

후보 생성 전체 시간은 184.209초입니다. 실패 3건은 응답 종료 사유가 `length`, 출력 토큰이 2,048이고 최종 답변이 비어 있었습니다. 이 사실만으로 내부 추론의 토큰 비중을 단정하지 않습니다. 재호출 없이 실패 기록을 보존합니다. 두 시점에 얻은 단일 실행의 관측이므로 통계적인 속도 차이나 설정 효과의 재현성을 뜻하지 않습니다.

## 독립 검토와 채택

설정·시간·토큰·이름 대응표를 가린 A/B 20개 패킷·40개 기록을 두 새 Codex 검증자가 나누어 검토했습니다. 76개 기준은 Boolean으로 판정했고 4개는 보류했습니다. 실패 답변 3개에 해당하는 6개 기준은 의료 판정 없이 생략하고 사전 정의한 생성 실패 0점으로 별도 처리했습니다. 정상 답변 33개는 기준 점수가 있고 4개는 점수 미정입니다. 전체 확정 점수는 없습니다.

범위는 보류 기준이 충족/미충족일 때 가능한 수학적 값이며 실측 확정 점수·의료 정답률·신뢰구간·공식 점수가 아닙니다. 실패 3건을 포함한 20개 전체를 분모에 유지했습니다. 이번 판정의 기준 점수 범위는 medium이 높지만, 새 안전 오류와 빈 답변 실패 3건, 보류 기준 4개 때문에 **전체 품질 개선의 채택 조건을 충족하지 못하여 미채택**했습니다. 기준 점수 밖의 사실·안전·환자 정보 출처·이력·누락·반복 쟁점도 별도로 보존했습니다. 기존 대조군에도 오류가 있습니다. 같은 대조군을 다시 평가한 판정은 과거 판정과 일부 다르므로 이전 회차 점수와 직접 빼지 않습니다.

평가용 180문항의 개별 자료나 피드백은 이번 설정 수정에 사용하지 않았고 해당 범위의 후보 호출은 0회입니다. 실제 NOVA 여러 턴 동작에 적용한 변경은 없습니다.

## 후속 조건

동일 medium/2,048토큰 후보를 다시 호출하지 않습니다. 추론 강도와 출력 예산의 관계를 확인하려면 다음 회차 전에 대조군과 한 변수만 다른 설계를 기록해야 합니다. medium과 출력 예산을 함께 바꾼 결과를 원래 low/2,048 대조군과 비교해 한 변수 효과로 해석할 수 없습니다. 새 호출은 별도 회차의 제한과 독립 검토 절차를 따릅니다.

[실행·검토 집계](validation.json), [검증 절차](CODEX_VERIFIER.md), [읽기 모드 화면](../local_tools/README.md)에 연결됩니다. 실제 질문·답변·기준·문항별 검토 근거는 로컬 비공개 결과에만 보관합니다. 공식 HealthBench/NOVA 점수 또는 임상 안전 인증은 아닙니다.
