## 가설과 변경

공식 가이드의 최종 기록 요구사항을 더 구체적으로 전달하면, 같은 진료 이력에서 근거 있는 계획과 사실 구분을 더 잘 기록할 수 있다는 가설이다. 대조군은 E03(참고점수42.483)이며, E03 최종 기록의 실제 누락을 확인했다는 뜻은 아니다. [조사 근거](NOVA_WEB_RESEARCH_20261012.md) · [공식 가이드](https://nova.snubhai.org/docs/#clinical-note)

제출한 10개 실행 파일 중 `run.py`의 `RECORD_PROMPT` 대입문만 바꿨다. 해당 부분을 제외한 바이트와 나머지 9개 파일은 고정 E03 ZIP과 동일하다. 다음 내용은 **최종 기록 지시 한 묶음**이며 각 문장별 효과를 분리하지 않는다.

- 검사 계획에는 필요한 검사와 근거를 적고, 계획을 시행·결과로 바꾸지 않는다.
- 치료·처치 계획은 환자에게서 확인한 정보에 근거한다. 약물·용량을 지어내지 않고, 확인되지 않은 복약·알레르기·금기는 미확인으로 남긴다.
- 추적 계획에는 근거 있는 재진 시점 또는 조건과 경고 증상을 적는다. 근거 없는 숫자로 정밀하게 꾸미지 않는다.
- 귀가·추적·의뢰 등의 방향과 이유를 설명하고, 근거가 부족하면 불확실성을 유지한다.
- 실제 SAY로 전달한 설명과 앞으로 필요한 교육 계획을 구분한다.
- 예선의 `O.tests`는 비워 두고, 진찰 턴 번호는 원문에 명시된 경우에만 쓴다. 현재 진료 이력에는 정확한 턴 번호 메타데이터가 없다.

STEP·REVIEW, 종료 설명 유도 시점, 검색, 추가 호출 경로, SDK1.0.1, medium, 2048/4096 출력 한도, 30턴 및 시간·사용량 보호는 유지했다. 최종 기록에 검색 원문을 새로 붙이지 않았다. 확정 양성/음성/미확인 구분은 기존 지침에도 있었으며 새 기능으로 세지 않는다.

## 검증과 제출 고정값

- 신규 합성 검사17개 및 독립 재검증17개 통과; private 전체547개 통과.
- public 지정9모듈142개 통과. 공개 저장소 전체 suite 결과가 아니다.
- 실제 고정 E03 ZIP과 새 ZIP의 격리된 합성 진료 요청·행동·최종 payload를 비교했다. 정규화 후 요청이 같고 RECORD system 메시지만 다르다. 각 경로의 가짜 chat 호출은5회이며 실제 모델 호출은0회다.
- 독립 코드·실제 ZIP 감사에서 차단 사유가 없었다. 출력 ZIP에는 명시한10개 실행 파일만 포함한다.
- E03의 전체 원문 제한 환경 prepare 시험은 이력이 보존된다. 준비 코드 바이트가 같지만 **E04에서 전체 원문 준비 시험을 새로 실행한 것으로 표시하지 않는다.**

## 해석 한계

프롬프트는 UTF-8 1,433→3,624바이트로 길어졌다. 추가 호출은 없지만 실제 토큰·시간은 달라질 수 있다. 4,096 출력 토큰에는 추론도 포함된다. 기존 JSON 파서는 임상 충실도나 이 지침 준수를 강제하지 않는다. 합성 응답으로 검증한 것은 전달·형식·원본 보존이며 치료 계획의 정확성이나 안전성은 미검증이다.

환자에게 실제 설명하는 행동은 바꾸지 않았다. 최종 기록 개선을 의사소통 개선이나 실제 처치 수행으로 간주하지 않는다. 같은 공개3샘플의 재사용, 서버 모델 digest 미공개, 실제 대화·기록의 독립 검토 부재를 유지한다. 총점뿐 아니라 영역 하락, 미완료·오류·턴·시간도 [실험표](NOVA_SAMPLE_EXPERIMENTS.json)에 기록한다. 안전 점수가 같아도 안전 오류가 없다는 증거는 아니다.

실제 원문·환자 대화·개별 평가·키·검색 DB는 공개하지 않는다. 빌더는 원본 및 실행 파일의 고정 해시를 확인하고 기존 결과 폴더 덮어쓰기를 거부하지만, 같은 UID의 모든 동시 파일 변경을 배제한다고 주장하지 않는다. 제출 후 고정 원문을 유지하기 위해 상속된 주석과 파일 끝 공백을 보존한다.
