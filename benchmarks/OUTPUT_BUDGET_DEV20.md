# 같은 medium의 출력 한도 개발 비교

가설은 같은 지침·원문 이력·medium 추론·temperature 0·모델 digest에서 출력 한도만 2,048에서 4,096토큰으로 바꾸면 빈 최종 답변을 줄일 수 있는지 확인하는 것입니다. 개발용 20문항 전체를 사용하며, 기존 medium/2,048의 정상 17개·빈 답변 실패 3개를 원문 그대로 대조군으로 보존합니다. low/2,048과 medium/4,096을 한 변수 비교로 해석하지 않습니다.

## 현재 단계

별도 budget 생성 경로를 구현·검증하고 2026-10-12 04:19:41–04:23:34 UTC에 개발 20문항을 각각 한 번 호출했습니다. 기존 low/2,048 대조군 gate와 기본 CLI는 유지합니다. 새 경로의 실제 payload·attempt에는 정확히 4,096토큰을 전달했고, 기본 2,048토큰 요청 바이트의 동일성도 합성 테스트로 확인했습니다.

| 관측 | cached medium/2,048 | 새 medium/4,096 |
|---|---:|---:|
| 생성 호출 | 기존 20 | 신규 20 |
| 정상 / 빈 답변 실패 | 17 / 3 | 18 / 2 |
| 잘림 / 차단 / 미호출 / 재호출 | 0 / 0 / 0 / 0 | 0 / 0 / 0 / 0 |
| 요청 시간 합 | 183.814초 | 232.219초 |
| 전체 실행 시간 | 184.209초 | 232.566초 |
| 입력 / 출력 / 총 토큰 | 7,464 / 18,184 / 25,648 | 7,464 / 23,794 / 31,258 |

새 실행의 모델 정보 조회 43회는 생성 20회와 별도로 기록합니다. 원래 실패 1개가 정상으로 바뀌었고, 기존 정상 답변 17개는 원문 바이트가 같습니다. 남은 빈 답변 2개는 length 종료·4,096 출력 토큰으로 기록되어 실행 상태는 partial입니다. 빈 답변의 length 종료를 비어 있지 않은 잘린 답변과 구분합니다. 요청 시간은 26.33%, 총 토큰은 21.87% 늘어난 단일 실행 관측입니다.

토큰 수는 API의 usage 보고값이며 completion_tokens를 내부 추론과 최종 답변으로 나눠 저장하지 않았습니다. 답변 검토와 화면에는 최종 답변만 사용합니다.

외부에서 고정한 비교·전체 summary SHA와 원문 답변·행·입력·지침·요청·설정·모델 핀을 호출 전과 실행 중 재검증합니다. 현재 모델 digest가 맞을 때만 문항당 1회·최대 20회를 호출하며 재호출하지 않습니다. 출처나 모델이 바뀌면 남은 호출을 멈추고 이미 시도한 기록·중단·미호출을 별도로 남깁니다. 원래 partial 상태와 실패 3개를 변경하지 않습니다.

설정·시간·토큰을 가린 A/B 패킷 20개·답변 기록 40개를 새 Codex 검증자 두 명이 나눠 검토했습니다. 기준 판정 70개·보류 6개이며 생성 실패 5개(대조군 3·후보 2)의 10개 기준은 판정에서 생략했습니다. 29개 기록은 기준 점수가 있고, 실패 5개는 별도 생성 실패 점수 0이며, 6개 기록은 점수 보류입니다. 동일한 17쌍의 답변에서 기준 판정 불일치는 0개입니다.

이번 새 검토의 가능한 기준 점수 범위는 **대조군과 후보 모두 56.67–63.33**입니다. 직전 추론 비교의 판정을 재사용하지 않고 대조군도 이번 패킷에서 다시 검토했으므로, 이전 범위와 연결해 개선율을 계산하지 않습니다. 빈 답변에서 회복한 1개도 기준 점수 0이며 새 중대한 의학적 안전·사실 오류가 확인됐습니다. 기준 품질 개선 미확인·남은 빈 답변 2개·보류 6개로 **미채택**입니다. 의심된 임상 사실은 공식 지침에 대조했으며 개별 원문·판정·근거는 비공개로 보관합니다. 실패·빈 답변은 의학적 기준을 임의로 미충족으로 바꾸지 않고 별도 생성 실패 0점 정책으로 구분합니다. 보류를 유지하고 전체 20개를 분모에 포함합니다. 빈 답변 감소와 사실·안전·이력·정보 출처의 품질 개선은 별도로 확인합니다.

private 전체 회귀 254개와 공개 패키지의 지정된 7개 모듈 131개가 통과했습니다. 공개 전체 테스트는 아닙니다. 새 budget 합성 22개·Git 없이 실행하는 payload 3개·준비 검사 41개를 포함하며, 독립 코드 감사와 공개 파일 범위 감사도 통과했습니다. 비교 파일의 일시적 변경 후 원문 복원, 후기 모델 digest 변경과 중단을 검사해 실제 호출 수·보존된 답변·준비한 패킷 수를 구분합니다.

서로 다른 시점의 캐시 대조군과 단일 새 실행을 비교하므로 재현성이나 일반적인 인과 효과를 입증하지 않습니다. 전체 시간·토큰·추가 모델 조회도 기록하며, 가능한 기준 점수 범위를 확정 점수나 의료 정답률로 표시하지 않습니다.

같은 medium/4,096 후보는 다시 호출하지 않습니다. 이 가설에서 시험한 후보는 하나이며 새 개발 근거와 한 변수 비교 계획이 검증될 때만 다음 회차를 시작합니다. 기존 보류를 없애기 위한 같은 자료의 반복 재판정은 외부 기준 확인이나 새 근거가 있어야 합니다.

고유한 전용 결과 폴더와 한 작성자의 소유 범위를 사용합니다. mkdir과 최초 inode 확인 사이 같은 UID의 빈 폴더 교체는 완전히 배제하지 못하는 문서화된 한계가 있으며 모든 동시 변경을 차단한다고 주장하지 않습니다.
