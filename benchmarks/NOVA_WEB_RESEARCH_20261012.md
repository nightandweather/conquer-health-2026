## 적용 범위

환자 행동 상한은 50턴이지만 E03은 최대 30턴으로 제한한다. 한 번의 SAY/EXAM은 30자 이하이고 최종 기록은 이 제한을 받지 않는다. 추가 검토 호출은 환자 턴을 쓰지 않아도 시간과 모델 비용을 소비한다. 무조건 턴·검토를 늘릴 근거는 아니다. [규칙](https://nova.snubhai.org/rules/)

샘플의 환자·진찰·채점은 Luna, 공식 평가는 Sol이다. 세부 채점표와 실행 산출물은 공개되지 않는다. 같은 공개 샘플 3건의 작은 차이를 독립 성능 개선이나 유의한 효과로 취급하지 않는다. [평가 안내](https://nova.snubhai.org/evaluation/)

Q&A도 예선 Doctor 고정·파인튜닝 불가·제출 중 외부 API 금지를 확인한다. 웹 조사는 개발 근거 수집이며 실행 중 검색 허용을 뜻하지 않는다. [공식 Q&A](https://nova.snubhai.org/qna/) 홈에는 예선 10/12–10/22가 표시됐고, 조사한 홈 메뉴에서 별도 공지 목록은 발견하지 못했다. [홈](https://nova.snubhai.org/)
