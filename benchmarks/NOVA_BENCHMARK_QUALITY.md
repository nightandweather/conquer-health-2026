# NOVA 제공 참고 벤치마크 품질 분석

2026-10-12 전체 파일을 실제 검사했습니다. **단계별 개발·자체 평가에 쓸 수 있지만, 제공 자료는 모두 외부 영어 참고 벤치이며 NOVA 숨은 평가 증례가 아닙니다.** 파싱 성공은 의학적 정답의 정확성을 보증하지 않습니다. 이번 작업은 모델 호출 0회이며 새 성능 점수·학습·프롬프트 수정·새 분할은 만들지 않았습니다.

## 전체 규모와 쓰임

| 데이터 | 실제 단위와 수량 | 적합한 확인 | 중요한 한계 |
|---|---:|---|---|
| AgentClinic-MedQA | 확장판 215 증례, 기본판 107은 확장판에 모두 포함 | 문진·진찰·검사·진단 행동 | 두 파일을 합쳐 322 독립 증례로 세면 안 됨; 원래 train/test 분할과 안정적 case ID 없음 |
| DDXPlus v2 | 합성 환자 1,292,579행, 질환 사전 49개, 증상·병력 사전 223개 | 다음 문진 질문과 감별진단 | 자연어 대화·진찰·검사 자료 없음; 기존 분할 간 완전 중복 있음 |
| ACI-Bench | 주 대화–진료기록 207쌍 | 마지막 진료기록의 충실도·누락·날조 | 진단 정답을 맞히는 자료가 아님; ASR 화자 오류는 별도 확인 필요 |

세 자료의 점수를 합쳐 하나의 ‘NOVA 성능’으로 해석하면 안 됩니다. 대회의 한국어 짧은 질문·행동 제한을 따르는 여러 턴 시험은 별도로 필요합니다. 한국어 번역·전환과 가상 환자의 답변 정확성은 이번에 검증하지 않았습니다.

## 실제 검사에서 확인한 항목

- **AgentClinic:** 기본 107, 확장 215 모두 JSON 파싱 성공. 필수 OSCE 필드의 누락·잘못된 타입 0, 파일 안의 완전/정규화 중복 0. 기본 107/107이 확장판과 원문 동일합니다. 검사 결과가 없는 확장 증례는 4/215(1.86%)로 배포 설명과 같습니다. 이는 선택 항목의 부재이므로 결과를 만들어 채우면 안 됩니다. 동일한 전체 입력에서 진단 문자열이 충돌한 그룹은 0이나, 진단 동의어·의학적 타당성·시험 문항에서 변환된 시나리오의 임상 정확성은 검증하지 않았습니다.
- **DDXPlus:** train 1,025,602, validate 132,448, test 134,529로 문서 수량과 일치합니다. 전체 행에서 필수값·나이 형식·성별·질환/증상 코드·허용 답값·첫 증상의 포함·감별 확률 범위와 합(허용 오차 1e-6)·질환 사전 참조 검사 오류 0입니다. 나이 관측 범위는 0–109, 각 분할에 49개 질환이 모두 있습니다. 학습 분할의 질환별 수량은 최소 261, 최대 64,368로 불균형하므로 전체 정확도와 질환별/매크로 지표를 함께 봐야 합니다. 사전의 223 evidence key에 대응하는 질문 alias는 209개이며 alias와 key가 다른 항목은 19개입니다. 코드 조인은 evidence key를 기준으로 해야 합니다.
- **ACI:** train 67, valid 20, test1/2/3 각 40으로 총 207입니다. 필수 ID·대화·기록의 빈 값 0, 주 데이터 안의 ID·대화 중복 0, 원래 분할 간 ID/대화 겹침 0입니다. 메타데이터는 모든 207개가 1:1로 연결되고 누락/행 증식 0입니다. `[doctor]` 또는 `[patient]` 표지가 없는 행이 2/207(0.97%) 있습니다. 이것은 형식 관찰이며, 태그가 양쪽 모두 있어도 내용상 화자가 뒤바뀌었는지는 판정할 수 없습니다. [원 배포자의 설명](https://github.com/wyim/aci-bench#data-splits-mediqa-chat--mediqa-sum-challenges)도 일부 ASR 화자 태그 반전을 명시합니다.

## 중복과 분할 간 겹침

DDXPlus 전체의 **완전 중복은 12,314그룹, 26,227영향 행/1,292,579(2.0290%)**입니다. 첫 행을 제외한 중복 잉여 행은 13,913입니다. 같은 전체 문진 입력 기준 중복은 14,266그룹, 31,590영향 행(2.4440%)입니다. 이 입력이 완전히 같은데 정답 질환이 다른 그룹은 0입니다. 이 숫자는 구조적 일치 검사이며 임상 정답 인증이 아닙니다.

| DDXPlus 분할 비교 | 완전 동일한 서로 다른 행 서명 | 오른쪽 분할의 영향 행 | 전체 문진 입력 동일 서명 | 오른쪽 분할의 영향 행 |
|---|---:|---:|---:|---:|
| train → validate | 1,625 | 1,643/132,448 (1.2405%) | 1,788 | 1,808/132,448 (1.3651%) |
| train → test | 1,802 | 1,823/134,529 (1.3551%) | 1,965 | 1,989/134,529 (1.4785%) |
| validate → test | 172 | 173/134,529 (0.1286%) | 172 | 173/134,529 (0.1286%) |

따라서 DDXPlus 기존 분할도 완전히 독립하지 않습니다. 원래 분할은 그대로 보존하고, 이후 실제 평가에서는 표준 분할 결과와 학습/개발에 노출된 동일 입력을 제외한 보조 결과를 따로 보고해야 합니다. 제외 여부는 답변 성능을 본 뒤 정하지 않고 입력 서명과 개발 노출 범위를 먼저 고정해야 합니다. 이번에는 제거·새 분할·모델 평가를 실행하지 않았습니다. 분할별 교집합은 중복될 수 있으므로 표의 영향 행을 단순 합산하지 않습니다.

ACI의 `src_experiment_data` 257행은 **기존 주 데이터의 152개 진료기록 서명과 모두 연결**됩니다. 105개 기록에 2개 변형, 47개에 1개 변형이 있고, 참조 기록 서명의 주 데이터 다대다 충돌과 원래 분할 불일치는 0입니다. 39개 실험 ID에는 서로 다른 정규화 대화가 연결됩니다. 주 데이터와 실험 데이터의 ID 체계가 달라 직접 ID 교집합은 0이어도 독립 사례는 아닙니다. 이 연결은 정답 기록 해시로 확인한 품질 감사 결과이며, 에이전트 입력이나 검색 자료로 정답 기록을 제공한다는 뜻이 아닙니다. 기록 해시가 환자 신원 자체를 인증하지도 않습니다.

## 다음 개발·평가에서 지킬 경계

1. 문진·진찰·진단은 AgentClinic, 문진 선택은 DDXPlus, 최종 기록 작성은 ACI로 따로 평가합니다. HealthBench는 외부 답변 품질 참고 자료로 유지합니다.
2. DDXPlus/ACI의 발표된 분할과 출처를 우선 보존합니다. ACI ASR 변형은 원래 encounter와 같은 분할에 묶고, DDXPlus는 위 중복을 표시한 표준 결과 및 고정한 중복 민감도 결과를 구분합니다.
3. AgentClinic은 기본판·확장판을 합쳐 나누지 않습니다. 215개 확장판의 원문 서명으로 고정된 ID를 부여한 뒤, 별도 검토 가능한 개발/평가 명세를 먼저 작성해야 합니다. 분할 비율·시드·평가 사례는 아직 선택하지 않았습니다.
4. 질환 정답, 감별 확률, 전체 미관측 증상, ACI 정답 기록은 채점 전용 자료로 분리해야 합니다. 제공 진료지침의 검색 색인에 넣어 정답을 찾아내게 하면 평가가 오염됩니다. 환자 시뮬레이터가 정답을 알고 있더라도, 에이전트에는 현재 질문에 허용된 답만 전달해야 합니다.
5. 번역·임상 검토·안전 항목·환자 답변 충실도·반복 질문·최종 기록의 출처와 시간/턴 제한을 평가해야 합니다. 공개 데이터의 모델 사전학습 노출, 질환별 대표성, 임상 정답의 정확성, 번역 후 의미 변화, 교차 데이터셋 의미 중복은 이번 구조 감사로 확인하지 못했습니다.

## 출처와 라이선스

공식 NOVA 참고 자료 README는 이 세 자료가 2026-10-10에 수집된 외부 공개 벤치이며 대회 평가 증례가 아니라고 설명합니다. 원본 묶음 SHA-256 `a2b4dbc6a2bc177a54cf7c7f1a4e15f94625bfd335738737b575c6832a1060a7`와 해제된 59개 파일을 ZIP 원문과 비교하고 감사 전후 일치함을 확인했습니다.
