# E05: 종료 설명 힌트 시점

2026-10-12. 구현·검사와 독립 감사를 마친 E05를 **20:59KST에 샘플 한 번으로 접수**했다. 현재 평가 대기, 점수·증례·서버 호출·토큰은 미확인이다. [실제 접수](https://nova.snubhai.org/submissions/eee34e55-73af-4b48-86f1-3a2ed386fac6/) 대조군은 E03이다. E04의 최종 기록 지시는 채택하지 않았고 이 후보에도 포함하지 않는다.

## 근거와 확인 범위

E03은 42.483점, 최종 기록 지시만 바꾼 E04는 41.079점이었다. E04의 검사·추적 점수는 실제 표시값 0.00/10이고, 의사소통은 1.83/15다. 점수만으로 실제 대화에서 무엇을 빠뜨렸는지는 알 수 없다. [실험표](NOVA_SAMPLE_EXPERIMENTS.json)

확인한 E03/E04 제출 상세 화면, 개발 가이드, 코드 평가 Q&A 답변에서 실제 제출 실행의 대화·최종 기록 열람 경로를 발견하지 못했다. 두 로컬 결과 폴더의 독립 조사에서도 해당 원문 저장본을 찾지 못했다. 공개 샘플 대본·예시 기록은 제출 실행의 산출물이 아니다. 기존 10월 10일 로컬 실행 검토도 E03/E04의 증거로 사용하지 않는다. 이는 확인한 화면과 폴더에 한정한 결과다.

[개발 가이드](https://nova.snubhai.org/docs/#clinical-note)는 최종 기록의 교육 계획과 실제 SAY 설명을 구분한다. 따라서 이미 존재하는 설명 힌트를 조금 앞당기는 기존 가설을 시험한다. 마지막 2턴 전에 설명이 불가능하거나 실제 설명이 없었다고 가정하지 않는다.

## 바뀌는 한 요소

고정 E03의 `next_step`에서 `if turns_left <= 2:`를 `if turns_left <= 6:`으로 바꾼다. 숫자 한 바이트 외의 실행 코드와 나머지 9개 파일은 동일하게 유지한다.

| 남은 로컬 행동 수 | E03 추가 힌트 | E05 추가 힌트 |
|---|---|---|
| 11 이상 | 없음 | 없음 |
| 10–7 | 문진 마무리·필요한 EXAM | 동일 |
| 6–3 | 문진 마무리·필요한 EXAM | 쉬운 말로 가능성 높은 진단·다음 계획 SAY |
| 2–1 | 쉬운 말로 가능성 높은 진단·다음 계획 SAY | 동일 |

6턴을 예약하거나 SAY를 강제하는 구현은 아니다. 기존 STEP/REVIEW/RECORD, 총 30행동 상한, SDK1.0.1, medium·2048/4096, 모델·temperature 미지정, 검색·출처 검증, 시간·호출·토큰 보호를 유지한다. 실제 모델 출력에 따라 행동과 문맥, 시간·토큰은 달라질 수 있다.

설명할 기회가 늘 수 있지만 남은 6–3행동의 EXAM 힌트를 대체하므로 정보 수집·진찰이 줄거나 결론을 서둘러 낼 위험도 있다. 6이라는 값이 최적이라는 근거는 없다. 방문 목적별 분기 설계는 이번 실행 코드에 적용하지 않는다.

## 검증과 평가 계획

고정 원본 해시, 정확한 한 바이트 차이, 경계별 실제 합성 요청, 초안·검토·검색·최종 기록 전달, 격리 ZIP 실행을 검사하고 독립 감사를 받는다. 합성 검사는 전달과 형식의 검증이며 실제 설명의 적절성·사실성·임상 품질을 검증하지 않는다.

이후 고정 ZIP을 승인된 샘플 한 번으로 시험한다. 공개 3증례, 각 최대 30행동이며 준비·진료 제한은 각각 10분·30분이다. 대기·빌드·채점 시간과 실제 서버 호출·토큰 비용은 미확인이다. 총점·6영역의 상승과 하락, 증례별 종료 상태·턴·초를 함께 기록한다. 관측 경과시간과 증례 시간 합을 구분한다.

반복 사용한 공개 3샘플과 서버 모델 digest 미공개, 실제 대화·기록의 독립 검토 부재라는 한계를 유지한다. 점수 상승만으로 검증된 임상 개선을 선언하지 않는다. 기존 E00–E04를 재제출하지 않고 공식 평가는 별도 승인 범위로 둔다.

원래 계획·관측·감사·실행 증거는 비공개 `results/codex-closing-six-agent-v1/`에 보존한다. 실제 질문·답변·기준·환자 원문·DB는 공개하지 않는다.
