# HealthBench 200문항 질문 유형과 검토 요청

신기원 교수님께 검토를 부탁드리기 위한 자료입니다. 복구한 HealthBench 계열 200문항을
로컬 gpt-oss-20b에 입력하고, 기본 호출과 사실 보존 지침 설정의 400개 기록을 Codex로
검토했습니다. 사용 문항의 넓은 질문 유형, 대화 이력 구성, 현재 결과와 다음 실험에서
확인할 사항을 정리했습니다. **2026년 10월 12일 원래 200문항 검토 및 후속 개발 실험의 상태**입니다.

## 사용한 질문 목록

[200문항 유형·분야 인덱스](HEALTHBENCH_QUESTION_INDEX.md)에서 문항별 넓은 분야,
질문 유형, 이전 대화 유무와 개발·평가 구분을 확인할 수 있습니다. 목록의 분류는
공유를 위한 자체 정리이며 공식 HealthBench 태그가 아닙니다. 문항 원문·번역·개별
사례의 상세 내용과 채점 기준은 포함하지 않습니다.

| 이번 실험의 입력 구성 | 문항 수 |
|---|---:|
| 개발용 | 20 |
| 평가용 | 180 |
| 이전 user·assistant 대화 이력 있음 | 81 |
| 단일 질문 | 119 |
| 합계 | 200 |

이력이 있는 문항은 마지막 질문만 떼어내지 않고 원래 역할과 내용을 복원해 전달했습니다.
채점 기준은 총 438개입니다. 복구 자료에는 원래 HealthBench ID가 남아 있지 않아
목록의 HB-V 번호는 로컬 관리용 번호이며, 공식 데이터셋의 문항 ID가 아닙니다.

## HealthBench 질문의 평가 목적

HealthBench는 의료 상황의 대화에서 마지막 사용자 발화에 대한 답변을 평가하고,
대화별 의사 작성 기준으로 필요한 내용과 피해야 할 내용을 확인합니다.
[OpenAI 공식 소개](https://openai.com/index/healthbench/)

| 공식 평가 주제 | 검토하는 질문의 성격 |
|---|---|
| 응급 상황 대응 | 신속한 진료 연결과 안전한 다음 행동을 안내하는가 |
| 불확실성 대응 | 정보가 부족한 상태에서 근거 없이 결론을 확정하지 않는가 |
| 의료 데이터 작업 | 제공된 정보를 정확하게 정리하고 기록하는가 |
| 지역별 의료 환경 | 지역·제도·자원 차이를 고려하는가 |
| 전문성에 맞춘 설명 | 일반 사용자와 의료인의 이해 수준에 맞게 답하는가 |
| 필요한 맥락 확인 | 답변에 필요한 정보를 적절히 확인하는가 |
| 답변의 깊이 | 요청에 맞는 충분한 내용과 설명을 제공하는가 |

이 표는 공식 벤치마크의 주제 설명이며 이번 200문항의 공식 주제별 분포를 뜻하지 않습니다.

## 원문 자료 접근

OpenAI는 학습 데이터 오염과 인터넷 검색을 통한 평가 누출을 막기 위해 예시를
텍스트나 이미지로 온라인에 다시 공개하지 말아 달라고 요청합니다.
따라서 이 공개 자료는 유형 인덱스와 집계 결과를 제공하며 원문은 공식 배포 경로로
접근하도록 안내합니다. [공식 안내의 각주](https://openai.com/index/healthbench/#footnotes)

- [공식 HealthBench 평가 코드와 자료 경로](https://github.com/openai/simple-evals/blob/main/healthbench_eval.py)
- [공식 HealthBench Main 원문 JSONL](https://openaipublic.blob.core.windows.net/simple-evals/healthbench/2025-05-07-06-14-12_oss_eval.jsonl)

공식 배포 파일은 이번 복구 200문항 파일과 다릅니다. 원래 ID가 없어 공식 파일에서
동일한 200문항을 자동으로 특정할 수 있다는 주장은 하지 않습니다.

## 현재 검토 결과

원래 두 설정의 생성 시도는 400회였고 343개 정상 완료·56개 출력 잘림·1개 생성 실패로
종료됐습니다. **400개 기록 검토 완료는 400개 답변의 정상 생성 완료와 구분됩니다.**

| 설정 | 정상 완료 | 출력 잘림 | 생성 실패 | 요청 시간 합 | 입력·출력 총 토큰 |
|---|---:|---:|---:|---:|---:|
| 기본 호출 | 143 | 56 | 1 | 3,229.667초 | 328,533 |
| 사실 보존 지침 grounded-v2 | 200 | 0 | 0 | 1,159.832초 | 178,452 |

기본 호출은 서버 기본 추론·temperature 설정을 사용했고, grounded-v2는
temperature 0·추론 low·최대 2,048토큰·문항당 1호출을 사용했습니다. 지침과 호출 설정이
함께 달라 이 차이를 프롬프트만의 효과로 해석할 수 없습니다.

Codex 검토는 기준별 Boolean 판정 834개, 보류 40개입니다. 생성 실패 답변의 기준 2개는
판정하지 않고 사전에 정한 실패 점수 0을 적용했습니다. 기준 점수가 있는 답변은 359개,
실패 점수 0인 기록은 1개, 점수 미정 답변은 40개입니다. 전체 확정 점수는 없습니다.

| 검토 범위 | 기본 호출의 가능한 기준 점수 | grounded-v2의 가능한 기준 점수 |
|---|---:|---:|
| 전체 200문항 | 20.83–25.17 | 50.33–54.92 |
| 평가용 180문항 | 20.83–25.65 | 50.37–55.46 |
| 이력이 있는 81문항 | 19.55–25.51 | 53.70–59.05 |

100점 척도로, 보류 기준을 충족 또는 미충족으로 판정할 때 가능한 수학적 범위입니다.
확정 점수·의료 정답률·신뢰구간·공식 HealthBench 또는 NOVA 점수가 아닙니다.
가중 기준 점수와 별도로 사실 오류, 환자 정보의 근거, 중요한 누락, 이력 모순과
가독성에 관한 메모를 남겼습니다. Codex의 검토는 의료 전문가의 검증을 대체하지 않습니다.

## 후속 개선 실험

개발 20문항에 일반 지침 후보 v3와 v4를 각각 적용해 새 답변 40개를 정상 생성하고,
설정·시간·토큰을 가린 A/B 답변을 독립 검토했습니다. 두 후보 모두 정확도 개선을
확인하지 못해 채택하지 않았습니다. 보류 기준은 각각 2개와 8개였으며 신규 후보를
평가용 180문항에 호출한 횟수는 0회입니다.

2026-10-12에는 원래 grounded-v2 지침과 대화 이력을 유지하고 추론 설정 low와 medium만 비교했습니다. 개발 20문항의 새 medium 답변은 정상 17개·빈 답변 실패 3개였고, 모델 digest와 입력 해시는 같고 요청은 reasoning_effort만 다름을 확인했습니다. 설정을 가린 새 독립 검증자 두 명이 40개 기록을 검토했고 기준 판정 76개는 확정, 4개는 보류했습니다. 이번 가능한 기준 점수 범위는 low 44.17–47.50, medium 52.50–56.67이지만 확정 점수는 아니며, 새 안전 오류·실패·보류로 채택하지 않았습니다. [추론 설정 비교 기록](REASONING_EFFORT_DEV20.md)에 시간·토큰과 검토 상태를 따로 남겼습니다. 저장된 이력에 대한 답변 개선과 실제 NOVA 여러 턴 진료 대화의 개선은 별도로 확인해야 합니다.

후속 독립 재확인에서도 보류 4개는 유지됐습니다. 기준의 판정 방향·적용 조건·근거 정의를 더 명확히 해야 하며 직전 점수와 미채택 상태는 바꾸지 않았습니다. 호출 없는 [출력 한도 비교 준비](BUDGET_CONTROL_PREFLIGHT.md) 뒤 별도 실행 경로로 같은 medium에서 출력 한도만 2,048→4,096으로 바꿨습니다. 신규 20호출은 정상 18개·빈 답변 실패 2개였고 기존 정상 답변 17개는 원문과 같습니다. 요청 시간 합은 183.814→232.219초, 총 토큰은 25,648→31,258로 늘었습니다. 설정을 가린 새 독립 검증자 두 명이 40개 기록을 검토했고 기준 판정 70개·보류 6개, 실패의 10개 기준 생략으로 종료했습니다. 이번 검토의 가능한 기준 점수 범위는 두 설정 모두 56.67–63.33입니다. 빈 답변에서 회복한 1개도 기준 점수 0이고 새 중대한 의학적 오류가 있어 채택하지 않았습니다. 직전 회차와는 별도의 판정이므로 이전 범위와 연결해 개선율을 계산하지 않습니다. [실제 출력 한도 비교 기록](OUTPUT_BUDGET_DEV20.md)에 생성·검토 상태를 구분합니다.

## 교수님께 검토를 부탁드리는 사항

1. **평가 지표** — 복구 자료의 예비 실험에서 가중 기준 점수와 함께 중대한 의료 오류·중요한 누락·근거 없는 환자 정보를 어떻게 측정하는 것이 적절할까요?
2. **보류 판정** — 근거 부족이나 기준 자체의 문제로 보류한 항목을 해결할 전문의 검토 절차와 평가자 간 일치도 기준을 어떻게 정하면 좋을까요?
3. **재현성** — 같은 대조군에 대한 Codex 재검토 판정도 일부 달랐습니다. 반복 평가와 블라인드 독립 검토를 어떻게 구성해야 작은 차이를 개선으로 오인하지 않을까요?
4. **독립 평가** — 개발 20문항과 평가 180문항의 규모·구성이 적절한지, 이미 평가 내용을 검토한 이후 새 가설을 검증할 독립 자료를 어떻게 확보하면 좋을까요?
5. **실제 진료 대화** — HealthBench의 복원 이력 평가가 NOVA의 질문·진찰·검사·최종 기록으로 이어지는 여러 턴 행동의 개선을 검증하려면 어떤 시나리오와 임상 검토가 필요할까요?
